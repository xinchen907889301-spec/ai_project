# 来源与核验清单

## 作者原稿

本课程依次依据四份用户上传文档：

1. 《金铲铲这个游戏.docx》：阵容构筑、连胜连败与节奏差。
2. 《回答补充问题.docx》：早期质量、装备定向、经济强化、转阵与启动。
3. 《回答ai提出的问题.docx》：共性优先、数据能力边界、停搜与牌池解释。
4. 《回答ai提出新的问题.docx》：复制器、课程目标、血量预算与数据网址。

作者自述千分王者，未独立核验。本版不虚构作者姓名、荣誉或学员效果，不增加官方认证。

## 忠实保留与编辑处理

| 原稿观点 | 整理处理 |
|---|---|
| 核心C、主T、羁绊与机制决定构筑 | 保留为主轴；补充成型可达性 |
| 两星低费质量优先，羁绊围绕质量 | 保留为默认策略，允许版本例外 |
| 通常至少一项经济强化 | 标为作者体系的重要偏好；不当成游戏硬规则 |
| 复制器适配2—3费赌狗，免费刷新适配一费 | 收入备注和版本待核验项，不写永久最优 |
| 高血量、版本支持时可考虑95 | 保留；补充升级后搜牌与购牌预算 |
| 晚启动不是普遍策略，常规需抢牌 | 明确区分三类节奏差 |
| 必吃鸡、稳前三、九成吃分等 | 改为有条件的上限或保分机会，不编造概率 |
| 没来牌基本不可能、没经济死路一条 | 去除绝对表述；区分随机、竞争与预算 |

“即时短板诊断”“搜牌时保留替代牌”“输出建议需校验合法性”等为整理者补充，未声称作者已经给出模型或验证结果。

## 数据访问状态

用户提供 `https://www.datatft.com/` 作为参考。在本次制作中，HTTPS访问返回代理隧道403，未能读取网站；未更改网络配置，也未绕过限制。没有核验此站的权威性、更新时效或与金铲铲具体模式的一致性。

本版无已完成的外部版本事实核验。课程正文使用机制共性与假设算例；具体数值不作为生产规则。
