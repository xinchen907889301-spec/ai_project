# 弈有章法｜第一版交付

## 文件

- `弈有章法_金铲铲定阵与运营课_v1.pptx`：可编辑16:9教学演示，包含讲师备注；采用自绘形状和文字，无第三方游戏图片。
- `课程讲稿.md`：逐页内容与讲师说明，便于作者审阅。
- `练习册与行动卡.md`：五道条件判断练习、参考讨论、复盘模板。
- `产品决策规则.md`：策略如何接入视觉识别、版本知识与LLM。
- `strategy_rules.json`：可机器读取的条件规则草案；不是可直接运行的策略引擎。
- `state.schema.json`、`advice.schema.json`：状态与建议数据格式草案。
- `来源与核验清单.md`：作者观点、编辑补充和待核验事项。
- `slides.json`、`build_course.py`、`build_strategy.py`：课程内容与可重复生成脚本。

## 使用

用PowerPoint或兼容软件打开PPTX。字体为Noto Sans CJK SC，缺失时可替换为微软雅黑、思源黑体等中文字体，随后检查换行。讲师备注可在备注视图阅读。

本版是可用于审阅、试讲与继续打磨的商品化课程初稿，尚未完成外部版本核验、作者最终审稿及真实学员反馈，不表述为已经验证效果的成品。展示目标为稳健上分，条件允许时追求第一。

## 再生成

```bash
python3 build_course.py
python3 build_strategy.py
```

依赖：python-pptx。课程内容在build_course.py，策略内容在build_strategy.py。生成后检查页面文本、讲师备注与JSON结构。预览联系图仅用于快速检查版式，不替代PowerPoint实际渲染。
