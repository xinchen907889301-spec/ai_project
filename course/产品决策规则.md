# 金铲铲局内助手｜策略规格 v1

## 目标与边界

默认服务萌新与中等玩家，目标为稳健上分；允许玩家切换为追求第一。工具提出有条件的建议，玩家完成操作。第一版识别自己的棋盘、备战区、装备与经济；对手信息仅从玩家主动侦察的画面获得，不假定掌握其他七人的实时完整状态。

本规格是产品设计与知识整理成果，不是已经实现或经过对局验证的推荐引擎。机器规则见 `strategy_rules.json`；状态与建议格式见 `state.schema.json`、`advice.schema.json`。

## 三层知识

| 层 | 内容 | 更新方式 |
|---|---|---|
| 原则层 | 资源适配、成型成本、血量预算、竞争与目标取舍 | 作者修订与案例反馈；保留修订历史 |
| 版本层 | 英雄、装备、羁绊、强化、牌池、概率、伤害、强势候选 | 按游戏、模式、赛季、补丁归档；变更后重新核验 |
| 对局层 | 自己与已侦察对手的可见状态、历史观察 | 带截图时间、置信度、缺失项；不把旧观察当作当前事实 |

视频用于发现候选策略和机制联动。高播放量只是筛选线索；不能代替强度证据。归档原链接、作者、发布时间、实际适用补丁、提取位置和人工审查结果。不将TFT数据未经检查直接用于金铲铲。

## 数据流

1. 玩家授权安卓系统屏幕采集，第一版由玩家点击“分析”。
2. 对稳定画面进行区域识别与OCR：棋盘、备战区、装备、商店、金币、等级、经验、血量和阶段。强化信息可能需要玩家打开页面补采。
3. 输出结构化状态。关键牌、星级、装备不确定时，先让玩家确认；缺失字段保持未知。
4. 依据版本知识枚举合法的上场组合、装备分配和候选阵容；按质量、功能与适配生成可解释的候选评估。评估标准需另行实现、测试和校准，不由LLM猜出分值。
5. 检索作者策略及版本经验，应用条件规则。LLM比较候选方案并解释取舍。
6. 校验建议合法性：预算、人口、持有牌、装备合成、强化触发条件和版本一致性。未确认的未来收入不计入已知预算。
7. 每次只展示一个主建议、一个替代方案、关键风险与下一观察点。建议显示生成时间；局势改变后标记过期。

## 输入字段与识别要求

| 字段 | 作用 | 不可见或不可靠时 |
|---|---|---|
| 游戏、模式、赛季、补丁 | 匹配正确规则 | 不生成具体阵容强度与机制建议 |
| 阶段、血量、金币、等级、经验 | 预算与节奏 | 请求补充；不建议精确搜牌金额或冲九时机 |
| 场上英雄、星级、位置 | 当前质量和上场候选 | 请求确认关键英雄与星级 |
| 备战区、对子 | 升星、替换和搜牌目标 | 不假设备战区没有牌 |
| 已装装备、散件、装备库 | 当前战力与继承路径 | 不建议无法确认的合成或装备转移 |
| 当前强化 | 收益、触发与阵容适配 | 请求打开强化页或手动选择 |
| 连胜/连败状态、最近战斗 | 当前路线与损血估计 | 不从单张截图猜测连续结果 |
| 已侦察对手 | 同行、目标牌占用 | 未侦察标未知；记录时间，不外推全部七人 |
| 玩家目标 | 保排名或追上限 | 默认稳健上分 |

不使用固定“90%识别置信度”作为跨设备门槛。门槛需要用实际标注截图校准；英雄ID、星级和装备等会改变推荐的字段应采用更严格的确认策略。

## 规则如何组合

优先级：版本与状态可信度 → 合法性 → 生存与即时补强 → 成型可达性 → 目标与上限。

经济强化是作者体系的重要偏好，而不是游戏必胜或失败的硬开关。没有经济强化时提高成型风险，并检查自然经济、来牌、已有战力与其他可量化收益。不能直接输出“死路一条”。

出现规则冲突时比较完整方案。例如“容错高可存钱”与“关键牌正在被抢”同时成立：需要将预算、目标剩余量、可替代战力和玩家目标放在一起，不按单句口号机械操作。规则条件评估为 `true / false / unknown`；未知不视为成立。

## 可解释建议样例（构造情景）

> **先补当前前排，暂缓冲九。** 你虽然有血量优势，但升级后预计无法支付必要的刷新和购牌成本。先用已持有的替代前排补战力，保留后续升级选择。风险：未侦察对手，无法保证这次补强能延续连胜。下一次分析请补充金币、经验和主T星级。

实际建议必须引用状态里的事实与对应规则。未计算预算时不能使用“预计无法支付”这类结论，而应改为“需要先确认升级后剩余预算”。没有经过统计校准，不输出吃鸡百分比。

```json
  "source_url": null,
  "source_author": null,

```

新补丁到来时，使受改动影响的记录进入待复核，而非把所有旧知识永久丢弃。未受影响的规则也需确认版本兼容后才能继续使用。记录回滚与冲突来源。

## 首版验证题

| 测试场景 | 期望行为 |
|---|---|
| 版本未知 | 请求确认；不编造当前强势阵容 |
| 主C识别不确定 | 请求玩家确认；不直接定阵 |
| 两星过渡核心、装备适配、未侦察 | 提示具备连胜潜力，不保证连胜 |
| 无经济强化但自然经济充足 | 评估预算，不直接判失败 |
| 主C二星、主T一星、占牌信息旧 | 提醒信息可能过期；条件化比较补强与上九 |
| 血量高但升级后无购买预算 | 警示无法转型成型，提供补当前质量的替代 |
| 目标牌被其他人持有 | 不将其解释为目标更好搜 |
| 同费其他牌被购买 | 仅在牌池机制已核验时解释相对影响 |
| 冲九损血估计区间过宽 | 展示不确定性，提供更稳路径 |
| 玩家选择追求第一 | 展示上限路线与风险，不许诺吃鸡 |
| 对手信息仅采集两家 | 不宣称完整比较八人战力 |
| 没有校准数据 | 不输出数字胜率 |

后续使用作者真实对局做盲评：先给局势，不给赛果，检查建议、理由与缺失信息提示。对局结果只能作为补充，不能将一场胜负当成策略正确性的唯一证据。
